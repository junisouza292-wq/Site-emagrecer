# Emagreça com Saúde

## Descrição
Site de dicas para emagrecer com saúde, incluindo:
- Receitas saudáveis
- Treinos e planos de exercícios
- Calculadora de calorias interativa
- Planos pagos com conteúdo exclusivo
- Área de contato para dúvidas

O site é responsivo e pode ser hospedado em GitHub Pages, Netlify ou qualquer servidor web.

---

## Tecnologias
- HTML5
- CSS3
- JavaScript (para calculadora de calorias)
- Estrutura simples, pronta para expansão

---

## Instalação / Uso
1. Baixe o arquivo `index.html` ou clone o repositório.
2. Hospede em qualquer servidor web ou serviço gratuito (GitHub Pages, Netlify).
3. Abra `index.html` no navegador para acessar o site localmente.
4. Para usar a calculadora de calorias, preencha os campos e clique em "Calcular".
