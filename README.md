# Emagreça com Saúde
## Descrição
Site de dicas para emagrecer com saúde, incluindo: receitas saudáveis, treinos e planos de exercícios, calculadora de calorias interativa, planos pagos com conteúdo exclusivo e área de contato para dúvidas. O site é responsivo e pode ser hospedado em GitHub Pages, Netlify ou qualquer servidor web.

## Tecnologias
HTML5, CSS3 e JavaScript (para calculadora de calorias). Estrutura simples, pronta para expansão.
